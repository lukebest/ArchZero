快速入门
怎么读这个看板？
  1. 左栏选一轮实验（Campaign） —— 一次 archzero run 就是一轮。
  2. 看顶部四格摘要 —— 候选数 / 活到终点的数量 / 停在哪一层 / 头号失败原因。
  3. 漏斗从左到右 —— 硬筛 → 对抗评审 → 解析模型 → 仿真 → RTL。数字是「通过 / 进入」。
  4. 点开候选 —— 看机制说明与各层裁决。需要对比两轮时，勾选两个 Campaign 再点「对比」。
