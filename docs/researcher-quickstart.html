ArchZero · 研究员快速入门

对照论文 Computer Architecture’s AlphaZero Moment（arXiv:2604.03312）的 Idea Factory： 人定问题与约束，机器跑 Generation + Tier0–5 Evaluation。遥测 Feedback 暂缓。

一分钟路径（离线可玩）

export CURSOR_API_KEY=cursor_...   # 实跑 LLM 时需要；看板可先离线
uv sync
uv run archzero doctor
uv run archzero seed-demo
uv run archzero ui                 # http://127.0.0.1:8787/

论文三层 ↔ 本仓库命令

论文模块你要做的事命令
规范 / 问题工厂写清目标、约束、验收、自由度new-spec / spec
Generation读论文、clean-room 出机制read / ideate
Evaluation Tier0–5漏斗过闸run --through tierN
Evolution对可执行实现做多样性搜索evolve --campaign
失败回流（Feedback 替身）从失败taxonomy生成下一轮问题next-questions
§5.1 范式 / 跨域理论透镜 + lateral/foundational 扩题frontier / run --expand-frontier
可复现产物打包问题包+候选+报告export
对比实验两轮 campaign 漏斗对比compare A B / 看板勾选
部署遥测 Feedback—暂缓

推荐工作流

  1. 出题：new-spec 或编辑 specs/*.md，条款 ID（CTX/REQ/ACC/DOF）保持稳定。
  2. 生成：有 PDF 时 ideate；否则 run --spec ... --n N 直接从问题包出候选。
  3. 漏斗：先 --through tier2 便宜过闸；需要仿真再开到 tier3/4（默认 stub）。
  4. 看结果：status / ui；失败模式用 next-questions 回灌下一轮问题包。
  5. 归档：export --campaign 留给组会或复现实验。

用量池提醒

所有 LLM 走 Cursor SDK。池1（composer / cursor-grok）扛高吞吐； 池2（Claude/GPT…）只用于合成与终审。archzero models 可自检路由。
